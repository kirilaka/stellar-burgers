# Stellar-burgers

## О проекте
Космическая бургерная — приложение для заказа бургеров онлайн.
Учебный проект Яндекс Практикума.

## Стек технологий
React, TypeScript, Redux Toolkit, React Router, Jest, Playwright

## Функциональность
- Конструктор бургеров с перетаскиванием ингредиентов
- Авторизация и регистрация пользователя
- Защищённые маршруты
- Лента заказов в реальном времени
- История заказов в личном кабинете
- Юнит-тесты (Jest) и интеграционные тесты (Playwright)

## Запуск проекта
npm install
npm run dev
